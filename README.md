# NeuroTopography

ระบบวิเคราะห์โครงสร้างเนื้อเยื่อจากภาพ MRI ด้วย Topological Data Analysis

## การคำนวณค่า Betti

ระบบสร้าง Vietoris–Rips complex จากกลุ่มจุด แล้วคำนวณค่า Betti โดยตรงจากนิยามของกลุ่มโฮโมโลยี

```
H₁ = ker ∂₁ / im ∂₂

β₀ = จำนวนกลุ่มที่เชื่อมถึงกัน        (union-find)
β₁ = dim ker ∂₁ − rank ∂₂
   = (E − V + β₀) − rank ∂₂
```

`rank ∂₂` หาจากการกำจัดแบบเกาส์บนฟีลด์ GF(2) โดยเก็บแต่ละคอลัมน์เป็น bitset

ระบบไม่ใช้สูตร `χ = β₀ − β₁` เพราะสูตรนั้นละ β₂ ไว้ ซึ่งไม่เป็นศูนย์เมื่อโครงสร้าง
มีสามเหลี่ยมจำนวนมาก การใช้สูตรดังกล่าวจะให้ค่า β₁ ต่ำกว่าความจริง

## การตั้งค่าอัตโนมัติ

| ขั้นตอน | วิธีการ | อ้างอิง |
|---|---|---|
| ค่าความสว่าง | Otsu's method — maximize between-class variance | Otsu (1979) |
| ลดสัญญาณรบกวน | Laplacian noise estimation | Immerkær (1996) |
| รัศมี ε | ช่วงที่คู่ (β₀, β₁) คงที่ยาวที่สุด | Stability Theorem |
